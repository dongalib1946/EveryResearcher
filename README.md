# 누구나 연구자 · 2026 수상작 아카이브

동아대학교 개교 80주년 누구나 연구자 경진대회의 수상작 전시 사이트입니다. GitHub Pages에서 정적 사이트를 제공하고, Google Apps Script가 기존 구글시트의 **수상작_아카이브** 탭만 읽습니다.

공개 사이트: **https://dongalib1946.github.io/EveryResearcher/**

Google Apps Script 전시 API가 연결되어 있습니다. 현재 공개 수상작이 없어 운영자 요청에 따라 **11팀의 샘플을 미리보기 표시와 함께 공개**합니다. 시트에 `published`를 체크한 수상작이 등록되면 다음 페이지 로드부터 실제 정보만 표시하며 샘플과 섞지 않습니다. API 연결 오류는 오류 안내로 표시합니다. 실제 수상작 운영을 시작할 때에는 `demoMode: false`로 변경하면 모든 행을 비공개로 바꿔도 샘플이 다시 나타나지 않습니다.

첫 화면은 사용자가 제공한 `0929(1).mp4`의 웹 최적화본을 한 번 재생하고, 이후 기존 8초 추상 모션 영상을 반복합니다.

## 빠르게 확인

Node.js 22 이상을 설치한 환경에서 이 폴더를 터미널로 열고 실행합니다.

```sh
npm run dev
```

브라우저에서 <http://127.0.0.1:4173> 접속. Windows PowerShell에서 npm 실행 정책 오류가 나면 `npm.cmd run dev`를 사용합니다. 서버 실행에는 추가 패키지 설치가 필요 없습니다. HTML 파일을 더블클릭하는 `file://` 방식은 모듈과 데이터 요청이 제한되므로 로컬 서버를 이용하세요.

## 페이지

| 파일 | 역할 |
| --- | --- |
| `index.html` | 영상 타이포그래피 · 수상 등급별 전시 |
| `archive.html` | 이름·주제·키워드 검색 · 시상 부문·연도 필터 |
| `about.html` | 대회 이야기 · 공식 포스터 · 시상 안내 |

| `apps-script/doGet-replacement.txt` | 기존 doGet 함수만 교체할 코드 |

## 연결과 배포

단계별 설명은 **[설치·운영 안내](docs/SETUP.ko.md)**를 보세요.

1. **기존 Apps Script 프로젝트**에서 `ResearchArchive.gs` 파일을 새로 만들고 제공된 내용을 넣습니다. 기존 `CONFIG`와 `getSpreadsheet_()`를 그대로 사용합니다.
2. 기존 파일의 `doGet` 함수 하나만 `doGet-replacement.txt` 내용으로 교체하고 `setupResearchArchive()`를 실행해 새 탭을 생성합니다.
3. 공개할 수상자 정보를 입력하고 `published`를 체크합니다.
4. 기존 추첨 배포의 버전을 유지하고, **새 전시 전용 웹 앱 배포**를 만듭니다. 새 URL 뒤에 `?api=archive`를 붙입니다.
5. `assets/js/config.js`의 `apiUrl`을 채우고 `demoMode: false`로 바꿉니다.
6. 프로젝트를 GitHub 저장소에 올리고 Pages의 Source를 **GitHub Actions**로 지정합니다.

샘플을 숨기려면 `demoMode: false`로 변경하세요. 공개 행이 없으면 공개 준비 안내를 표시합니다. `demoMode: true`일 때도 API 연결 실패 시에는 샘플로 대체하지 않습니다.

## 인터랙션

- PC 첫 화면은 헤더와 ‘누구나 연구자’ 영상 타이포그래피가 화면 높이를 채웁니다. SciVal 연구동향분석과 포스터 전시를 설명하는 문구는 다음 스크롤 영역에 배치했습니다.
- 첨부한 약 8초 오프닝 영상을 큰 한글 안에서 한 번 재생한 뒤, 기존 추상 모션 영상으로 부드럽게 전환하여 반복 재생합니다. 페이지를 새로 열면 오프닝부터 시작합니다.
- 재생 종료까지 사용자의 스크롤·터치·키보드·클릭이 없을 때에만 전시 시작점으로 이동합니다.
- 사용자가 조작했거나 다른 탭을 보고 있거나 동작 줄이기를 설정했으면 자동 이동하지 않습니다.
- 현재 영상의 일시정지·재생이 가능합니다. 자동 재생이 차단되면 재생 버튼을 표시합니다. 반복 영상이 끝날 때에는 다시 자동 스크롤하지 않습니다.
- 동작 줄이기 또는 데이터 절약 설정에서는 정지 이미지를 먼저 보여줍니다.
- 수상작 목록, PDF에 로딩 상태와 오류 안내를 제공합니다. 프로필 오류 시 기본 이미지를 표시합니다.
- 모달은 Escape로 닫을 수 있고, 포커스는 클릭했던 카드로 돌아갑니다.
- 총장상 1팀의 대형 전시, 최우수상 2열, 우수상 3열, 장려상 5열로 구성했습니다. 작은 화면에서는 열 수를 조정합니다.
- 수상자 이름·제목·설명은 HTML로 실행하지 않고 텍스트로 표시합니다.

## 영상 교체

첫 영상은 `assets/media/opening-film.mp4`, 첫 정지 화면은 `opening-poster.jpg`입니다. 첨부한 4K HEVC 영상을 1920×1080 H.264로 변환하고 오디오를 제거했습니다. 원본 파일은 수정하지 않았습니다.

반복 영상은 `assets/media/research-motion.mp4`, 대체 정지 화면은 `intro-poster.jpg`입니다. 오프닝에는 `loop`가 없고, 두 번째 영상에만 `loop`를 적용했습니다. 교체 시 같은 파일명으로 소리 없는 H.264 MP4를 넣으세요.

`CONFIG.autoScrollAfterIntro: false`로 바꾸면 자동 이동을 끌 수 있습니다. 기본 반복 영상의 생성 코드는 `scripts/make-assets.py`, 사용자 영상의 변환 코드는 `scripts/prepare-opening.py`에 포함되어 있습니다.

## 검증

```sh
npm install
npm test
npm run dev
# 별도 터미널에서 실행, 설치된 Chrome 필요
npm run test:browser
npm run build
```

단위 테스트는 공개 여부·고유 ID·시상 인원·시트 읽기 범위·링크 검증을 확인합니다. 브라우저 테스트는 실제 Chrome에서 검색, PDF 모달, 오류 재시도, 깨진 이미지 대체, 공개 준비 상태, 390/768/1440px 레이아웃, 영상 종료 및 자동 이동 조건을 확인합니다. 실제 Google 계정의 권한·조직 정책과 실제 제출 PDF의 미리보기 가능 여부는 연결 후 확인해야 합니다.

## 자산

- 80주년 로고, 도서관 로고, 공식 포스터: 사용자가 제공한 원본. 도서관 로고의 심벌은 원본 이미지에 CSS 표시 영역을 적용하고 옆에 읽기 쉬운 기관명을 배치했습니다.
- 오프닝 영상: 사용자 제공 `0929(1).mp4`의 웹 최적화본.
- 반복 영상, 샘플 프로필 SVG, 샘플 PDF: 이 프로젝트에서 제작한 확인용 자료. 실제 수상자 사진이 아닙니다.
- 타이틀 글꼴: Noto Sans KR 900, SIL Open Font License. 로컬 서브셋 및 라이선스는 `assets/fonts/`에 포함합니다.
- 참고 사이트의 영상과 자산은 복사하지 않았습니다. 제공된 화면의 큰 영상 타이포그래피를 디자인 참고로 사용했습니다.

외부 API 주소를 제외한 기본 전시 자산은 모두 저장소에 포함되어 있습니다. 빌드 결과는 `dist/`에 생성되며, 그 안에는 Apps Script 소스·테스트·운영 문서가 포함되지 않습니다.
